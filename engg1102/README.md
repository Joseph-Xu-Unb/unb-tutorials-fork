# ENGG 1102

[Getting started with UNB IDE](projects/getting-started.md) is a small simulator-first exercise: show a greeting, respond to logical button A with a heart, and clear the micro:bit display with logical button B. It does not use BLiXels or declare course syllabus or assessment requirements.

- Publication reviewer: the UNB-ECE repository maintainer. Course/instructional approval from the course instructor is pending; retain the **Instructor preview** card label.
- Uchechi's workflow: author lessons and assets in their own repository, preview/debug with the UNB IDE Tutorial Tool, then propose a synchronization PR into this collection. The source repository and synchronization action still need configuration under [#182](https://github.com/UNB-ECE/unb-platform/issues/182).
- Check registered dependencies, image paths, source revision and proposed catalog metadata during import. Never replace other collections or central configuration wholesale.
- Any physical test needs separate board, firmware, program and outcome evidence. This introduction is runnable in the simulator and makes no physical-validation claim.
